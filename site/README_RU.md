# Сайт CoolPackHelper

Статический сайт проекта на русском и английском языках для GitHub Pages. Он собирается через Node.js без клиентского фреймворка, внешних шрифтов, аналитики и серверных сервисов. Рекомендуется Node.js 24.

## Локальный просмотр

```powershell
cd site
npm ci --ignore-scripts
npm run build
npm run check
npm run preview
```

Откройте <http://127.0.0.1:4173/CoolPackHelper/>. После изменения исходников снова выполните `npm run build`. Preview-сервер отправляет `Cache-Control: no-store` и читает новую сборку без перезапуска.

Сгенерированная папка `site/dist/` игнорируется Git. В коммит должны попадать исходные файлы; GitHub Actions самостоятельно создаёт новый артефакт для публикации.

## Содержимое и исходные файлы

- `docs/ROADMAP_EN.md` и `docs/ROADMAP_RU.md` служат источниками дорожной карты. Строки этапов на главной извлекаются из заголовков и статусов. Сохраняйте структуру `## Milestone N — …` / `## Этап N — …` и `**Status: …**` / `**Статус: …**`.
- `docs/GUIDE_EN.md` и `docs/GUIDE_RU.md` создают полные страницы документации.
- `site/build.mjs` содержит общий шаблон, переводы главной страницы, ссылки загрузки и ссылки BMProjects.
- После модерации страницы Modrinth установите `distribution.modrinthPending` в `site/build.mjs` в значение `false`.
- `site/style.css` содержит адаптивное оформление.
- `site/cph_logo_new.png` используется как логотип в шапке, на странице выбора языка и во вкладке браузера.
- `site/theme.js` применяет режим «Система», «Светлая» или «Тёмная» до отрисовки страницы. По умолчанию используется системная тема браузера или ОС.

Обе языковые версии работают без JavaScript. При доступном JavaScript корневая страница выбирает сохранённый язык или язык браузера, а без JavaScript показывает отдельные ссылки на русскую и английскую версии.

## Публикация на GitHub Pages

Отправьте изменения исходников в `main`. Workflow **Website** соберёт, проверит и опубликует `site/dist/`. В настройках репозитория должен быть выбран источник **Settings → Pages → Build and deployment → Source → GitHub Actions**.

Публикация выполняется не сразу. Дождитесь успешного завершения заданий `build` и `deploy`. Сейчас GitHub Pages разрешает кэшировать HTML до 10 минут, поэтому после завершения workflow отдельный браузер может некоторое время показывать предыдущую версию. Сборка добавляет версию коммита к адресам CSS, JavaScript и изображений, чтобы файлы разных публикаций не смешивались.

Опубликованный сайт доступен по адресу <https://bmprojects-development.github.io/CoolPackHelper/>. Если после успешного деплоя и окончания времени кэша браузер всё ещё показывает старую страницу, обновите её с обходом кэша.

Изменения только сайта и документации не запускают workflow сборки мода. Для собственного домена или форка задайте `SITE_URL` во время сборки и обновите ссылку репозитория в `build.mjs`.
